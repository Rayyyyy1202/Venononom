# 后台运营功能与日常操作说明

> GWM Europe 官网 AI 智能客服 · 上线后业务团队的"工作台"
> Version 1.0 · 适用对象：GWM 业务 / 内容运营 / 销售管理 / 客服主管

---

## 0. 这份文档解决什么问题？

业务团队常问：
> "上线后我们每天打开后台做什么？看哪些数字？怎么改话术？预约试驾的客人怎么跟进？"

下面把后台拆成 **7 个功能模块**，每个都给出：
- 模拟界面（ASCII mockup，能贴 PPT）
- 谁来用、用来做什么
- 是 **MVP 阶段就有**，还是 **进阶 / 完整版**才提供
- 哪些操作 **甲方 GWM 自己负责**

```
│  └─────────────────────────────────────────┘                      │
└────────────────────────────────────────────────────────────────────┘
```

**关键指标的定义：**

| 指标 | 含义 | 怎么算 |
|---|---|---|
| 对话总数 | 用户开了聊天面板并发送 ≥1 条消息的会话数 | 每个 sessionStorage ID 计 1 |
| 平均时长 | 用户首条消息到最后一条消息的时间间隔 | 不算无人值守的空白 |
| 解决率 | 用户没点"踩"也没说"转人工"就关闭的比例 | 1 - (踩数 + 转人工请求数) / 对话数 |
| Token 成本 | OpenAI 当日累计 token × 单价 | 来自 OpenAI usage API |

> **MVP 即有**：对话总数、Token 成本、待处理 inbox
> **进阶版**：平均时长、解决率、24h 趋势图
> **完整版**：实时大屏、自定义看板、跨年同期对比
